# 「WutheringWavesUID幫助」機器人隱私權政策
>版本日期： v1.0

歡迎您加入「共鳴基地」Discord 社群並使用「WutheringWavesUID幫助」機器人服務（以下簡稱「本服務」）。本隱私權政策旨在說明我們如何收集、使用、處理、分享及保護您的個人資料。當您使用本服務時，即表示您同意本隱私權政策的條款。

### 第一章：我們收集的資訊

我們在您使用本服務時，可能會收集以下類型的資訊：
直接提供的資訊：
* Discord 帳戶資訊： 當您加入本社群或使用機器人時，我們會獲取您的 Discord 使用者 ID、使用者名稱、伺服器暱稱、頭像 URL。
* 機器人互動的訊息內容： 機器人會讀取您在頻道中輸入的指令和相關訊息內容，以便處理您的查詢並提供服務。您的訊息內容資料不會儲存在 Discord 平台外 (Discord 之外)。
* 遊戲相關資訊： 當您使用機器人查詢遊戲數據（例如角色練度、抽卡紀錄）時，您可能需要提供遊戲 UID 或其他相關資訊，以便機器人讀取並分析您的遊戲數據。
* 贊助資訊： 若您選擇贊助我們的服務，我們不會直接收集您的支付卡號或其他敏感支付資訊。這些資訊由第三方支付平台（例如 PayPal）處理。我們僅接收支付* 平台提供的訂閱狀態、訂閱層級及與您 Discord ID 相關聯的必要資訊，以便提供贊助者權益。
* 自動收集的資訊：
* 互動數據： 機器人會記錄指令的使用次數、錯誤報告等互動數據，用於分析機器人效能和改善服務。
* 技術數據： 伺服器日誌可能會記錄您的 IP 位址、連線時間等基本技術資訊，用於服務的維護和安全性考量。

### 第二章：資訊的使用目的
* 我們收集您的資訊主要用於以下目的：
  * 提供和維護服務：
   * 執行您透過機器人發出的指令，提供角色分析、抽卡查詢、攻略等核心功能。
   * 確保社群的正常運作，維護社群秩序。
   * 處理您的查詢和提供技術支援。
* 改善和優化服務：
   * 我們可能會對您的訊息內容資料進行匿名化和去識別化處理，用於分析用戶行為模式，以改進現有功能、開發新功能，並提升機器人的整體效能和用戶體驗。訊息內容資料不會用於訓練機器學習或人工智慧模型。您的遊戲數據（例如練度分析、抽卡紀錄）經過去識別化處理後，可能用於生成全服排行榜、統計數據分析，以提供更全面的社群洞察。
   * 執行協議與規範： 確保您遵守本服務條款及社群規範。
   * 提供贊助服務： 根據您的贊助層級，提供相應的機器人功能和專屬服務。

### 第三章：資訊的分享與揭露
* 我們承諾不會將您的個人資料出售、出租或分享給第三方，除非在以下情況：
* 取得您的同意： 在明確取得您的同意後，我們才會分享您的資訊。
* 服務提供者： 我們可能與必要的第三方服務提供者合作，例如伺服器託管服務、數據庫服務，這些服務提供者將僅在為我們提供服務的必要範圍內存取您的資訊，並受保密協議約束。
* 法律要求與保護： 當法律要求、政府機關要求，或為保護我們、使用者或公眾的權利、財產、安全時，我們可能會揭露您的資訊。
* 匿名化數據： 我們可能會分享已完全匿名化和去識別化的數據，這些數據無法追溯到任何特定個人。

### 第四章：資訊的儲存與安全
* 儲存地點：
* 您的 Discord 訊息內容資料不會儲存在 Discord 平台之外（僅用於即時指令處理）。
其他必要的數據（例如贊助狀態、綁定的遊戲 UID、機器人使用紀錄等）可能儲存在我們託管的伺服器或第三方數據庫服務中。
* 資料安全： 我們會採取合理的技術和組織措施來保護您的個人資料，防止未經授權的存取、使用、披露、修改或破壞。這包括使用加密、存取控制、防火牆等安全技術。然而，請理解，網路上的資料傳輸並非百分之百安全，我們無法保證您的資訊在傳輸或儲存過程中的絕對安全。
* 資料保存： 我們將在達成收集目的所需的期間內保留您的個人資料，除非法律要求或允許保留更長時間。

### 第五章：您的權利
* 作為使用者，您對您的個人資料擁有以下權利：
* 查閱權： 您有權向我們查詢、閱覽您的個人資料。
* 複製權： 您有權要求複製您的個人資料，但我們可能會收取必要的工本費。
* 更正/補充權： 當您的個人資料有變更或不正確時，您有權要求我們更正或補充。
* 刪除權： 您有權要求我們刪除您的個人資料。但這可能導致部分機器人功能無法使用。
* 停止處理/利用權： 您有權要求我們停止收集、處理或利用您的個人資料。
* 撤回同意權： 您有權隨時撤回對某些數據處理的同意，但撤回同意不影響撤回前已進行的合法處理。
* 拒絕檢閱權： 您可以選擇不讓其訊息內容資料被檢閱。

本服務不面向13歲以下的兒童。若您是未成年人，請在您的法定監護人陪同下使用本服務，並確保您的監護人已閱讀並同意本隱私權政策。若我們發現收集了未經監護人同意的未成年人資訊，我們將盡快刪除該資訊。
