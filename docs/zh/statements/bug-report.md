# 提交 BUG 报告

嗨！漂泊者，您如果在使用机器人的时候发现有任何问题，皆可提交！！


## 在提交之前

在发起新的 问题 之前，请务必完成以下检查清单：

- [ ] 确认当前问题是否有得到解决，善用爬文或常见问题板。
- [ ] 再社群中询问该问题是否有得到社群解决。
- [ ] 在已知问题板中查询是否有相同问题。

若经过上述步骤后仍未找到解决方案，你可以在 Discord 社群中发起新的问题提交

## 如何提交？

### 提交问题前的准备

在提交时，请确保提供以下信息：

1. **设备信息**

   - [ ] 你的UID。
   - [ ] 你是否完成上面的清单呢。

2. **问题描述**

   - [ ] 详细描述你的问题，使开发人员能够根据你的描述复现问题。
     - 问题是如何触发的？
     - 系统显示了怎样的错误提示？
     - 你尝试了哪些操作来排查问题，结果如何？

3. **指令使用错误**

- 如果你的问题涉及到数据库结构错误，请第一时间联系管理员或芙檩并立即排解问题。

### 提交 问题 的方法

- 前往 共鸣基地 社群中寻找 意见反馈 频道并提交问题。

## 协助解决

当管理员无法协助解决时请等待开发者 芙檩 上线协助处理。


### 让开发者协助前准备

1. 整理问题后说明

此将帮助我更快速地解决问题，感谢你的支持！
