# 项目说明

::: center
![banner](https://img.alicdn.com/imgextra/i1/1797064093/O1CN01vWmKzl1g6e2VIEODU_!!1797064093.png_.webp)
:::

WWUID 是一款为《鸣潮》玩家设计的工具，旨在通过分析面板和查询功能。它主要以 Discord 机器人命令的形式提供服务，帮助玩家查询游戏分析数据、获取 WIKI 资料等 。

## WWUID 功能一览

WWUID 提供了一系列以 `@艾特机器人` 为前缀的 Discord 指令，涵盖了账号管理、数据查询、WIKI 资料等多个方面。

### **账号管理**

  * **绑定 UID**: 使用 `綁定[UID]` 指令绑定您的 UID，例如 `綁定700000001`.
  * **查看您的 UID**: 使用 `ww查看` 查询已绑定的 UID.
  * **删除 UID**: 使用 `刪除[UID]` 删除特定 UID.
  * **删除全部 UID**: 使用 `刪除全部特徵碼` 删除所有已绑定的 UID.

### **信息查询**

  * **Discord 分析**: 使用 `分析` 上传角色面板.
  * **练度统计**: 使用 `練度` 查询角色的练度分析.
  * **修改声骸**: 使用 `改[角色]套裝[套裝名]` 或 `改[角色]聲骸` 修改角色声骸.
  * **基本信息**: 使用 `卡片` 查询所有角色的基本信息，包括角色、等级、共鸣链和佩戴武器
  * **查询面板**: 使用 `[角色]面板` 或 `[角色]面包` 查询特定角色的详细信息，例如 `ww椿面板`
  * **查询角色伤害**: 使用 `ww[角色]傷害/傷害1/傷害2` 或 `[角色]傷害3/傷害4/傷害5` 查询角色单人或配队伤害
  * **查询角色权重**: 使用 `ww[角色]權重` 查询角色声骸评分的权重及标准
  * **面板偷窥与 PK**: 可以查询他人的角色面板或练度，如 `[UID] [角色]面板`，并能进行面板 PK，如 `[UID][角色]面板PK`
  * **兑换码**: 使用 `兌換碼` 查看当前有效的兑换码
  * **卡池倒计时**: 使用 `卡池倒計時` 查看卡池倒计时 还可以使用 `未復刻角色` 和 `未復刻武器` 查看多久未复刻的角色及武器
  * **持有率**: 使用 `鏈率[up/all]` 查看角色共鸣链持有率 。使用 `持有率[up/all]` 查看角色持有率.

### **抽卡记录**

  * **导入抽卡链接**: 使用 `導入抽卡鏈接/連結` 从游戏里导入抽卡记录.
  * **查询抽卡记录**: 使用 `抽卡記錄` 查询玩家的抽卡记录.

### **WIKI**

  * **角色攻略**: 使用 `[角色]攻略` 查询角色攻略，如 `椿攻略`.
  * **角色共鸣链/技能**: 使用 `[角色]共鳴鏈` 或 `[角色]技能` 查询相应资料.
  * **武器/声骸介绍**: 使用 `[武器名稱]介紹` 或 `[聲骸名稱]介紹` 查询特定武器或声骸资料.
  * **武器/套装列表**: 使用 `[武器類型]武器` 或 `套裝列表` 查询列表.
